# Sheerherb.cn — 国内站 B2B 采购询盘版

本项目用于 `https://sheerherb.cn`，中文站 `/` 与 `/zh/` 面向中国企业采购、研发和产品开发人员；保留七种语言路径（zh / en / de / ja / es / ru / it）。

## 本轮全站改版范围

- 首页：采购导向的产品入口、质量规格核对、应用场景、采购流程和询盘 CTA。
- 全站页眉/页脚：统一品牌色、导航、商务邮箱与询盘入口；补齐质量与文件导航。
- 产品目录：按植物提取物、脂质体相关原料、定制寻源分类，并展示国际站代表性产品方向。
- 产品详情：增加原料身份、来源工艺、关键指标、检测方法、质量文件和采购条件核对清单；不虚构具体参数或库存。
- 质量与文件：突出 COA、TDS、SDS、批次资料、检测方法及目的市场合规核对，并说明逐项目确认原则。
- 定制寻源、应用领域、关于我们等内页：统一为采购决策型页面结构，提供相关页面跳转和询盘 CTA。
- 联系页面：增加采购信息准备提示；从产品页进入时自动带入关注产品。
- 移动端：增加全站固定询盘入口和更适配手机的内容布局。

## 品牌与内容原则

延续国际站 Sheerherb 的活性物质载体系统、微球技术和纳米脂质体技术定位，同时用更符合国内采购决策的表达方式呈现产品、规格、质量文件和供货沟通。产品可供性、参数、检测方法、文件范围、MOQ、交期和贸易条款均按具体项目及供应商/批次文件确认，不将示例信息表述为保证。

## 本地运行

Windows PowerShell 中进入项目目录：

```powershell
npm.cmd install
npm.cmd run dev
```

打开 `http://localhost:4321/`。根路径默认进入中文首页 `/zh/`。

构建：

```powershell
npm.cmd run build
```

生成文件位于 `dist/`。

## Supabase 询盘配置

项目保留原询盘提交逻辑。部署环境需设置：

```env
PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
PUBLIC_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
```

请勿将 `service_role` 或任何私密密钥放入前端或 `PUBLIC_` 环境变量。请在 Supabase 中启用适当的 RLS 策略，并测试询盘是否成功写入 `inquiries` 表。

## GTM / GA4

- GTM 容器：`GTM-ND9Z73J6`
- 表单成功事件：`inquiry_submit_success`

事件仅在 Supabase 返回成功后推送。不要向 GA4 发送姓名、邮箱、电话、公司名称或表单自由文本等个人信息。

## 发布前检查

1. 在本地检查 `/zh/`、产品目录、四个产品详情、质量与文件、定制寻源、应用领域、关于我们和联系页面。
2. 测试产品详情页“询问该产品”是否自动填入关注产品。
3. 测试 Supabase 表单、移动端固定询盘入口、GTM 事件和七语言切换。
4. 核对企业名称、电话、邮箱、地址，以及具体产品参数、质量文件、MOQ、交期和贸易条款。
5. 运行 `npm.cmd run build`，在 Cloudflare 预览环境检查后再正式部署。

## 安全说明

交付源码包不包含原始 `.env`、`.git` 历史、`.astro` 缓存、`node_modules` 和 `dist`。请勿把私密密钥提交到公开仓库。
