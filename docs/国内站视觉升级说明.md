# Sheerherb.cn 国内站视觉升级说明

## 设计定位

国内站采用“高级植物原料供应商”的视觉方向：以国际品牌式的克制、留白和材质感建立信任，以清晰的 B2B 采购信息结构帮助访客快速扫描并提交需求。

## 本次调整

- 品牌色更新为深植物绿、自然暖白、柔和鼠尾草绿与植物砂金。
- 导航、按钮、页眉、页脚统一为低饱和、轻量、专业的视觉体系。
- 首页 Hero 从抽象科技球体改为植物原料标本式视觉展示，围绕植物提取物和功能性原料表达业务方向。
- 首页标题、模块标题采用更有编辑感的衬线字体栈，正文继续使用易读的无衬线字体栈。
- 产品卡片、采购流程、质量文件、知识中心、文章页、询盘表单统一边框、留白、色彩和交互状态。
- 内页页头统一为暖白底色与轻量植物纹理装饰，强化页面层级。
- 移动端优化导航换行、首页标本视觉、卡片单列和询盘表单。
- 更新浏览器主题色，与新品牌主色一致。

## 业务表达边界

本次为视觉与界面样式调整，不增加未经确认的自有工厂、生产线、认证、库存、产能、纯度、MOQ 或交期承诺。供应状态、规格、质量文件和商务条件仍按项目及供应商实际资料确认。

## 国内站与国际站关系

本次只调整 `sheerherb.cn` 国内站 Astro 项目，不修改 `sheerherb.com` 国际站。两站保留品牌视觉亲缘关系，但页面结构和内容侧重点可分别服务各自市场。
