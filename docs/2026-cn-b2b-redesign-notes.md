# Sheerherb.cn 国内站 B2B 采购转化改版说明

## 本轮目标
以 sheerherb.com 国际官网为品牌视觉与技术表达参考，将国内站调整为面向中国企业采购、研发、配方和供应链人员的原料采购沟通入口。重点优化产品发现、规格判断、质量资料核验、供货条件沟通与询盘路径。

## 已实施的源码修改
- 首页 Hero 改为国际官网公开展示的西安设施实景图，强化真实企业识别，不再使用抽象球体占位视觉。
- 首页重点产品卡片增加产品/技术图片，避免四张卡片共用同一张图。
- 首页技术模块使用国际官网发布的脂质体结构示意图和原料图像。
- 首页“原料与样品、应用与配方、质量文件与批次”三张专题卡片改用国际站已有图像资源。
- 全站通用页面 Hero 根据页面主题切换为不同的国际站图片：质量与检测、应用技术、企业设施、产品/原料等。
- 全局视觉升级为与国际站一致的植物绿、自然暖白、低饱和金色体系；调整导航、按钮、卡片、页面标题、表单、侧栏和移动端布局。
- 保留现有中英文路由、SEO 数据、询盘表单和 Supabase 提交逻辑，不改动数据库字段及前端密钥配置。

## 重要的内容边界
国际官网中对不同产品发布的规格、MOQ、检测方法、认证或质量表述不应自动套用到所有产品。国内站继续以具体产品页、正式规格书和对应批次文件为准；未核实的库存、交期、产地、认证、纯度和自有生产能力不得作为确定承诺。
