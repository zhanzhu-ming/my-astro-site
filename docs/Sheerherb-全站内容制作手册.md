# Sheerherb.cn 全站内容制作手册

## 1. 内容定位

**高级植物原料供应商（Premium Botanical Ingredients & Sourcing）**。视觉表达克制、有材质感；信息组织清晰、可扫描、可转化。网站服务 B2B 品牌方、膳食补充剂企业、食品及化妆品制造商、原料经销商和研发采购团队。

## 2. 内容语气

- 专业但不堆砌术语；清楚解释采购人员需要确认什么。
- 先讲原料身份、规格、应用和文件，再讲采购流程与合作方式。
- 避免“行业领先、顶尖工厂、全球第一、绝对安全、保证效果”等无法验证的宣传词。
- 不将合作供应商的工厂、认证、设备、库存、产能、交期描述为 Sheerherb 自有能力。
- 不在未获得资料时填写纯度、含量、CAS、原产地、MOQ、价格、认证和交期。

## 3. 页面内容架构

| 页面 | 内容任务 |
|---|---|
| 首页 | 快速理解 Sheerherb 的原料方向、服务方式、质量沟通和询盘入口 |
| 产品目录 | 按原料类别找到产品，并跳转到身份、规格和文件核对内容 |
| 植物提取物 | 明确植物学身份、使用部位、提取工艺、标志性成分和检测要求 |
| 脂质体相关原料 | 说明活性物、载体、剂型、包封率、粒径和稳定性等需要确认的项目 |
| 定制寻源 | 展示需求梳理、供应评估、文件核对、样品协调和商务确认流程 |
| 应用领域 | 按营养、食品饮料、个人护理、研发及制造采购说明不同关注点 |
| 质量与文件 | 解释 COA、TDS、SDS、检测方法、批次追溯和目的市场资料 |
| 采购知识 | 15 篇采购指南，覆盖规格、质量文件、供应商、样品、脂质体参数 |
| 关于我们 | 讲清业务定位、工作方式、合作原则和供应商角色边界 |
| 工厂与供应链 | 教采购方核验实际生产主体、场所、样品批次和交付文件 |
| 供应商资质与认证 | 解释证书持有人、范围、场所、有效期及产品文件区别 |
| 项目合作 | 说明可沟通的项目类型，不虚构客户案例和订单成果 |
| 联系我们 | 收集成分、规格、应用、数量、市场和文件需求 |
| 隐私与条款 | 说明询盘信息用途、网站信息性质和交易文件优先级 |

## 4. 视觉素材

`public/images/editorial/` 内包含原创 SVG 编辑式插画：
- `botanical-still-life.svg`：植物原料、树脂与粉末的品牌静物图
- `ingredient-lab.svg`：样品和研发场景
- `application-worlds.svg`：营养、食品、个人护理和研发应用
- `sourcing-process.svg`：采购协作流程
- `quality-records.svg`：COA、TDS、SDS 文件主题

这些是原创品牌视觉插画，不是 Sheerherb 实际工厂、设备、实验室或产品实拍。若用于展示真实产品外观、工厂、证书或检测现场，应替换为经确认的真实照片。

## 5. 视频制作状态

已准备 3 支短片的中英文脚本、旁白、镜头表和素材清单，位于 `docs/video-production/`。当前源码包没有虚构的 MP4 文件。正式制作需要真实原料、包装、实验室、人员或供应商现场素材，并确认拍摄授权；未提供真实素材前，不应把生成或示意画面宣传为 Sheerherb 自有生产现场。

## 6. 上线前需业务方确认

1. Sheerherb 的法定运营主体名称、注册地址及对外联系方式。
2. 是否有可公开使用的团队、办公场景、仓储或实验室照片。
3. 四个重点产品的最新规格书、CAS/身份依据、检测方法和批次 COA。
4. 合作供应商的实际生产主体、证书持有人、证书范围和有效期。
5. 可提供的样品政策、MOQ、包装、库存、交期和贸易条款。
6. 隐私政策中的数据保存期限、处理主体、删除请求邮箱和第三方服务清单。
7. 图片、视频、客户标识和供应商文件的使用授权。

## 7. 内容维护原则

规格、证书、产品身份、检测方法、价格、库存、MOQ 和交期属于动态业务信息。每次更新时记录来源、确认日期、适用产品、批次或供应主体；过期信息应及时撤下或标注需重新确认。
