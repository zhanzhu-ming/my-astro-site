# 原料观察短片脚本｜A Closer Look at Ingredients

**时长：** 30 秒  
**用途：** 产品目录、应用领域页面  
**形式：** 3–4 组微距镜头，突出质地、形态和信息标签；不出现未经核实的产品参数。

| 时间 | 镜头 | 屏幕文案 |
|---|---|---|
| 0–6s | 植物叶片、根茎或原料来源静物 | 原料身份 / Ingredient identity |
| 6–12s | 粉末、树脂或液体样品微距 | 形态与规格 / Form and specification |
| 12–18s | 样品标签和批次信息 | 批次与文件 / Batch and documentation |
| 18–24s | 应用研发或配方观察 | 应用条件 / Application context |
| 24–30s | 品牌片尾和询盘入口 | 按项目确认 / Reviewed project by project |

## 中文旁白

认识一种原料，不止看名称和外观。植物身份、使用部位、提取工艺、关键指标与检测方法，共同构成采购判断的基础。先把信息确认清楚，再讨论适合项目的供应选项。

## English voice-over

Understanding an ingredient goes beyond its name or appearance. Botanical identity, plant part, extraction process, key parameters and analytical methods all inform a purchasing decision. Clarify the details first, then review supply options for the project.

## 需要的真实素材

- 目标产品的实物样品和经确认的标签
- 供应方提供的规格资料或可公开的文件局部
- 经授权的原料处理、取样或研发画面
- 产品外观、颜色和形态必须与实际供应批次一致
